# optsim 光学仿真台（桌面版）

手术显微镜 可见光 / NIR 荧光 四路成像的光学仿真：光线追迹、自动对焦、NIR 焦差与查表、四路配准、P–ν 玻璃图与复消色差组合搜索。

## 在 Windows 上运行

**方法一：双击运行（推荐）**
1. 把整个 `optsim-source` 文件夹解压到任意位置（路径里最好不要有中文）。
2. 双击 `Run-optsim-Windows.bat`。
   - 第一次运行会自动安装 Python 和所需的包，要联网，大约 5 分钟。电脑上没有 Python 时，它会用 Windows 自带的 winget 装 Python 3.12。
   - 以后再双击，几秒钟就打开。
3. 想从头重装，删除文件夹 `%LOCALAPPDATA%\optsim` 再双击。

**方法二：生成独立的 optsim.exe（不需要装 Python）**
1. 在 GitHub 上新建一个仓库，把本文件夹的全部内容（包括隐藏的 `.github` 文件夹）上传。
2. 仓库的 Actions 页会自动开始打包，约 10 分钟。
3. 打包完成后，在那次运行的页面底部下载 `optsim-Windows`，解压后双击 `optsim.exe`。
   同时也会生成 `optsim-Linux`（在 Ubuntu 22.04 上编译，兼容性最好）。

## 在 Xubuntu 上运行

**已打包版本**：解压 `optsim-linux-x64.tar.gz`，在文件管理器里双击 `optsim/optsim`（需要 Ubuntu/Xubuntu 24.04 或更新）。

**源码方式**：在本文件夹里双击 `run-linux.sh`（选“在终端中运行”）。第一次会建 Python 环境，要联网。如果提示缺 venv，在终端运行一次 `sudo apt install python3-venv`。

## 四个页签

| 页签 | 用途 |
|---|---|
| 系统参数 | 工作距离、物镜/筒镜焦距、立体基线、光阑、分光方式、变倍档、色差校正方案。点“应用并标定”自动设计镜头、标定物面和传感器位置。可导出镜片处方 CSV，可保存/载入配置。 |
| 光路与对焦 | 变倍档、物深、视场、音圈筒镜位移、NIR 微调轴，实时看四路离焦/焦深、侧视光路、弥散斑、焦移随波长曲线。一键可见光自动对焦、NIR 自动微调。 |
| 全档分析 | 每档在 Δz = −d / 0 / +d 自动对焦，算 NIR 残余离焦、最优固定垫片、每档查表微调值、NIR→可见与左右配准的多项式残差。可导出 CSV/JSON。 |
| P–ν 玻璃图 | 476 种玻璃（成都光明、肖特、小原、萤石、熔石英）。点选三种看三角形、各片光焦度、450–850 nm 焦移；自动搜索最佳三玻璃组合；“应用到镜头设计”把组合送进系统参数，用真实光线追迹重新设计和评估。 |

## 说明
- 镜头自动设计结果缓存在 `~/optsim/design_cache.json`（Windows 为 `C:\Users\你\optsim\`）。复消色差和自定义三玻璃组合第一次设计要 2–3 分钟，以后秒开。
- 处方是自动设计的起点，没有做公差分析，不能直接投产。
- 玻璃色散数据来自 refractiveindex.info（公共领域），取自 Optiland 软件包里附带的那一份。
